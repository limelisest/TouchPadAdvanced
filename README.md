# TouchPad Advanced

.NET 10 + WinUI 3 的 Windows 触控板边缘与四角手势工具。

支持八个沿边方向、四个边缘向内方向和四角内滑，共 16 个可配置触发项。

## 启动与系统托盘驻留

固定发行目录为 `release/`（完整路径：`E:\Git\TouchPadAdvanced\release\TouchPadAdvanced.exe`）。系统需要 .NET 10；发布目录包含 Windows App SDK 运行组件。

一键构建、注册开机自启并启动到固定发行目录：

```powershell
.\run.ps1
```

程序启动后自动在系统托盘（通知区域）驻留图标：
- 默认开启“关闭窗口时最小化托盘”：点击窗口右上角关闭按钮将隐藏窗口到系统托盘，后台持续识别手势。
- 左键点击或双击托盘图标可重新唤起主窗口。
- 右键点击托盘图标可快速打开主窗口、暂停/继续手势、切换观察模式或彻底退出程序。
- 应用使用单实例，重复启动会自动唤起并激活现有窗口。

## 配置与界面交互

顶部导航栏提供“手势配置”和“设备与状态”两个标签页：

- **区域绑定摘要与状态预览**：触控板预览居中显示，四边和四角按钮直接显示当前已绑定的方向与动作摘要（如 `←后退 · →前进`、`↑音量+`），未绑定区域弱化显示；触控板中央实时统计已绑定手势数量（`已绑定 X / 16 项手势`），触控时实时显示手势阶段、起点锚点与滑动轨迹虚线，触发手势时对应区域高亮脉冲。
- **自适应平移与缩放**：点击四边或四角后，预览向反方向平滑让位并根据窗口可用空间自适应尺寸，确保配置面板与触控板预览同时清晰可见。点击空白处、触控板中央或“返回全貌”取消选择并复位。
- **范围拖拽与实时百分比标签**：点击“调整范围”切换到拖拽状态，预览回到中央，四条蓝色边界手柄旁直接显示实时百分比气泡（如 `上 8.0%`）。支持鼠标拖拽或聚焦后按方向键以 0.5 个百分点微调（允许 2%–20%）。
- **灵敏度与设置**：点击右上角“灵敏度与设置”，右侧以紧凑双列布局展示启用手势、拦截手势移动、观察模式、打字防误触、开机自启、关闭窗口最小化托盘开关，以及触发距离、音量/滚轮步长和切换选择步长参数。
- **固定保存区与实时触发反馈**：底部状态栏左侧显示当前运行状态与最近一次触发的手势动作；右侧在修改配置后显示“保存并生效”按钮，保存成功后显示“已保存”并禁用。

| 默认手势 | 动作 |
| --- | --- |
| 下边缘向左滑 | 鼠标侧键 1：后退 |
| 下边缘向右滑 | 鼠标侧键 2：前进 |
| 右边缘向上滑 | 增大音量 |
| 右边缘向下滑 | 减小音量 |
| 其他方向 | 未绑定，可自行配置 |

所有方向均可绑定：后退、前进、音量增减、静音、媒体控制、**向上/向下/向左/向右连续滚轮滚动**、**增大/减小屏幕亮度**、上一个/下一个任务、任务视图、开始菜单、显示桌面、虚拟桌面切换、快速设置、通知中心、资源管理器或自定义快捷键。

配置文件位于 `%LOCALAPPDATA%/TouchPadAdvanced/edge-settings.json`。旧版统一宽度和 12 项绑定自动兼容读取，原有动作保留。保存时验证配置并原子替换文件。

## 手势规则与防误触

- 单指可直接在边缘或角落落下，也可先在中央移动指针、不抬指进入已绑定区域。进入区域时立即接管指针，并以入边位置作为新起点；入边前的移动不计入手势距离，进入本身不触发动作。
- 边缘中段沿边滑动触发沿边动作，垂直向中心滑动触发边缘内滑。
- 四角交叠区保留斜向中心的四角内滑和相邻边的沿边动作。四边垂直内滑从各边中段开始，避免与角落冲突。
- 普通动作每次落指最多执行一次；**沿边音量、沿边垂直/水平滚轮、沿边屏幕亮度**按滑动距离连续步进调节，且支持同一次接触中反向滑动调节。
- **打字防误触**：开启后，当检测到物理键盘正在输入普通字符键（排除 Ctrl/Alt/Win 组合快捷键）及停止输入后的 350ms 冷却期内，手掌擦碰触控板边缘将被自动抑制，防止打字时误触边缘手势。
- **触控板长宽比自适应**：自动从 HID 描述符读取触控板 X/Y 逻辑范围计算长宽比，按真实比例渲染预览面板。
- 多指、按压、低置信度接触、接触 ID 变化或输入中断会取消当前手势，并等待全部抬指。
- Ctrl+Alt+F8 在注册成功时可暂停或恢复识别；也可使用右上角的暂停按钮或系统托盘菜单。

## 设备与状态诊断

“设备与状态”页提供设备选择、连接状态、触控板比例、报文长度、当前与历史峰值触点数、指针钩子拦截统计、最近 8 条手势触发记录，以及一键最小化到托盘和导出 JSON 诊断文件功能。

## 验证

```powershell
dotnet run --project tests/TouchPadAdvanced.Tests.csproj -c Release -- --self-test --output artifacts/self-test.json
```

73 项自动检查覆盖 HID 帧、全部手势方向、方向竞争、误触排除、连续音量/滚轮/亮度、打字防误触与起点跟踪、指针所有权与释放、独立范围、旧配置迁移、配置持久化、Windows 动作编码、输入线程和真实系统钩子调用。

发布版支持 `--smoke <输出路径>`。此模式以观察模式启动真实 WinUI 窗口，检查 16 项绑定、8 个区域入口、4 个拖拽手柄、各方向及窄屏面板位置、固定保存区、编辑状态和配置读回，并导出应用自身的界面图。
